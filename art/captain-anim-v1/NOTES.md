# Captain animation pilot — 10 retained frames

Built-in image generation tool only. Painted back frames first, then profile frames. Exactly 10 selected PNGs are in `out/`; two generated candidates per frame (20 candidates total). All selected files are native 1024 × 1536, 8-bit RGBA PNGs, copied byte-for-byte from the tool's saved output. No resizing, repainting, alpha repair, installs, git, or other network operations were performed.

## Pilot result / unresolved failures

**None of the ten frames meets all production acceptance requirements.** Costume, identity and illustrative rendering are broadly consistent, but the tool repeatedly introduced a diffuse tan/violet halo, approximate rather than exact pose transfer, and a camera closer to eye level than the specified downward view. Retries explicitly requested removal of the halo and exact guide endpoints but did not solve these defects within the two-candidate limit.

The generated preview and saved-file transparency must not be treated as production-ready. A direct alpha decode of the selected PNGs found **no alpha=255 pixels in any frame**: all nonzero alpha values are partial. A direct saved-file preview of `idle_profile_00.png` showed mainly the faint halo with the figure invisible; another saved back-frame preview showed the figure. This preview discrepancy and the defective alpha mean the assets require inspection before any use. The alpha-zero exterior / crisp ≤3px edge requirement was not achieved. Four files also have nonzero alpha within the outer 16px margin (see table). Files have been preserved exactly as generated rather than procedurally repaired.

“Kept” below means the best available candidate within the limit, **not** production approval. No fully accepted first frame was obtained for either facing; the first retained frame of each facing was nevertheless attached to subsequent frames as the requested rendering consistency reference, with explicit instructions to omit its erroneous halo. No additional frames were painted.

First profile submission was rejected before generation because referenced_image_paths allows at most 5 paths. Removed the redundant front still; no image candidate was produced by that validation failure.

# Try it

Stapledon's Voyage is **pre-alpha**. Packaged builds currently support Macs with
Apple Silicon. Windows and Linux downloads are not available yet.

## Latest development review

The latest review includes local interstellar clouds and dust, bridge consoles,
black-hole hover/orbit and guided planetary stops. Free navigation starts at rest
near Earth, mouse movement looks around by default, and panels release the pointer.

With GitHub CLI and Google Cloud CLI authenticated for the development bucket:

```sh
gh api repos/sunholo-data/stapledons-godot/contents/tools/install_review_build.sh --jq .content | base64 -d | bash -s -- --dev
```

The installer verifies the download against the development manifest. This review
uses the authenticated development bucket; the earlier public download below
has a different feature set and controls. [Gallery](/gallery) and [News](/news)
show the new work.

## Ship controls in the latest review

| Control | Action |
|---|---|
| **Mouse movement** | Look around; the pointer is captured during ordinary ship viewing |
| **Tab** | Open details, help and **Walk to** buttons; release the pointer for buttons |
| **W A S D** | Walk when a panel is not using the pointer |
| **E** | Use the console or lift in reach; step back from a console |
| **M** | Open the read-only star chart |
| **Hold I** | Release the pointer to identify and click a visible star or body |
| **P** | Pause or resume simulation time, preserving the course |
| **Esc** | Close the top panel or card; otherwise return to the main menu |
| **7 / 8 / 9** | Look forward, to the side or aft |
| **J** | Adjust sky brightness |
| **Enter** | Continue an interlude or dismiss the arrival card |

To plan a destination, use **Tab → Walk to → Navigation station**, then **E**.
Select a star or a body from the stable **In this system** list, inspect the plan
and confirm **Commit**. A committed journey continues to its planned arrival;
pause holds time and does not cancel that course. Stops are inertial standoffs.

Use the **Voyage console** to start the guided voyage and the **Archive terminal**
to read unlocked physics entries and news from home.

The chart shows local clouds by default. **Interstellar medium [D]** toggles the
layer while the chart is open; **Local ISM** frames the nearby clouds. Their
angular outlines come from published source figures, while near/far depths are
approximate. **Depth guides** adds the optional radial construction lines.

## Review limitations

The bridge art and lighting continue to develop; see [concept art](/concept-art).
Local warm clouds and hot gas ship in this review. Dense-cloud tomography and the
Local Leo Cold Cloud remain deferred pending scientific checks. Black-hole
rotation and the true Galactic-Centre background remain future work.

The app is unsigned. If macOS refuses to open it, use System Settings → Privacy &
Security → Open Anyway. [The roadmap](/docs/roadmap) records the remaining acceptance
work for the complete journey, sky, ship and planetary experience.

## From source

You need Godot 4.7 or later and the pinned AILANG version (see the repository's
`CLAUDE.md`).

```sh
git clone https://github.com/sunholo-data/stapledons-godot.git
cd stapledons-godot
make import
make sky-assets
make catalogue-inputs
make catalogue TIER=large
godot --path .
```

The default launch opens the title menu. Choose **Board the ship** for free
navigation. `make run` opens the standalone map; `make voyage` opens the diagnostic
sky flight with its separate developer controls.

`make test` runs the headless suite; `make golden` checks shaders against CPU
references; `make capture` renders reference images for visual inspection.

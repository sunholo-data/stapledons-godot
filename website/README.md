# Stapledon's Voyage website

The showcase site for Stapledon's Voyage, built with [Docusaurus](https://docusaurus.io/)
3.10.2, the same version and theme as [AILANG World](https://www.sunholo.com/ailang-world/) and
the [AILANG docs](https://ailang.sunholo.com). It is served at
**https://www.sunholo.com/stapledons-godot/**, the same way AILANG World is served: legacy GitHub
Pages from the root of the `gh-pages` branch, under the org's custom domain.

The site builds locally to static files. It does not depend on GitHub Actions.

## Build

Requires Node.js 20 or newer. From the repo root:

```bash
make site            # npm ci (first time) + build into website/build/
make site-serve      # build, then preview at http://localhost:3000/stapledons-godot/
```

or by hand:

```bash
cd website
npm ci
SITE_URL=https://www.sunholo.com BASE_URL=/stapledons-godot/ npm run build
SITE_URL=https://www.sunholo.com BASE_URL=/stapledons-godot/ npx docusaurus serve
npm run start        # dev server with live reload, http://localhost:3000/
```

The build fails on any broken internal link (`onBrokenLinks: 'throw'`).

`url` and `baseUrl` come from the environment at build time:

| Variable | Default | For the live site |
|---|---|---|
| `SITE_URL` | `https://sunholo-data.github.io` | `https://www.sunholo.com` |
| `BASE_URL` | `/` | `/stapledons-godot/` |

`make site` passes the live values (`SITE_URL`, `SITE_BASE` in `mk/site.mk`).

## Publish

**Publishing is Mark's call.** Nothing publishes the site automatically.

```bash
make site-deploy          # build, then push website/build to the gh-pages branch
DRY=1 make site-deploy    # the same, but stop before the push and show the commit
```

`tools/site_deploy.sh` clones `gh-pages` into a temporary directory (or starts an orphan
`gh-pages` the first time), replaces its tree with `website/build`, adds `.nojekyll`, commits and
pushes to `origin`. It never uses a git worktree and never switches branches in your checkout.
`SITE_REMOTE=<url>` pushes somewhere else.

**One-time Pages setting** (repository settings, or `gh`): source = branch `gh-pages`, folder
`/` (legacy build). No `CNAME` file is needed: the org's Pages domain already maps project sites
to `www.sunholo.com/<repo>/`, as it does for `ailang-world`.

```bash
gh api -X POST repos/sunholo-data/stapledons-godot/pages \
  -f build_type=legacy -f 'source[branch]=gh-pages' -f 'source[path]=/'
```

## Media

| What | Where | Why |
|---|---|---|
| Videos (MP4 H.264 + WebM VP9) | `gs://stapledons-voyage-assets/site/<sha256>.<ext>`, public, immutable | Kept out of git; content-addressed like the sky textures |
| Video manifest | `src/data/media.json` | Written by `make site-media-publish` |
| Posters (first frame of each clip) | `static/img/posters/<clip>.jpg` | Small, so the page paints before a video loads |
| Gallery stills | `static/img/gallery/*.jpg`, listed with captions in `src/data/gallery.js` | |

The clips are frame-exact captures of the game itself. `tools/site_movie.gd` (run through
`main.gd --movie=CLIP`, or `--map --movie=map`) drives the AILANG simulation and the camera and
saves one PNG per frame; nothing is composited or graded.

```bash
make site-media                    # render (GPU window) + encode every clip into renders/site/
make site-media CLIPS="voyage map" # just some
make site-media-publish            # maintainers (gcloud): upload --no-clobber, rewrite media.json
```

| Clip | What | Note |
|---|---|---|
| `hero` | `voyage` without the HUD | the homepage background |
| `voyage` | forward view, rest → 0.99c at 1 g | |
| `lookaround` | a full turn in yaw at 0.99c | |
| `map` | galaxy map orbit, cruise slider 0.9c → cap | rendered at 1600×900, the `--map-capture` size |
| `cmb` | forward, 20° lens, γ 100 → 707 | needs the forward CMB disc (M1.8, PR #79); on a tree without it the clip shows stars only |

The published `cmb` clip was rendered from the PR #79 tree. Encoding needs `ffmpeg` with libx264
and libvpx (`brew install ffmpeg`, or `FFMPEG=$(npx -y ffmpeg-static)`).

Look at every frame you publish (contact sheets: `ffmpeg -i renders/site/frames/CLIP/f%05d.png
-vf "select='not(mod(n,100))',scale=640:-1,tile=3x2" -frames:v 1 sheet.png`).

## Writing pages

- The landing page is `src/pages/index.js`; the gallery is `src/pages/gallery.js`.
- Docs pages live in `docs/`; the sidebar is autogenerated (order with `sidebar_position`).
  Use `.mdx` to embed a clip: `import {ClipFigure} from '@site/src/components/Clip';` then
  `<ClipFigure name="voyage" caption="…" />`.
- **Say what exists and what is planned.** Mark captures from unmerged work as in review, and
  keep the roadmap page's date current. Numbers come from the design repo's check values
  (RS-n, HB-n) or from real captures, never from memory.
- Links between pages: relative file links with the extension (`[roadmap](roadmap.md)`).

## Theme

`src/css/custom.css` is the AILANG family stylesheet (copied from AILANG World, which copies the
AILANG docs site): Sunholo palette (primary `#e73c17`, dark mode `#ff5a3c`), Montserrat headings,
Inter body, JetBrains Mono code. Site-only rules are at the bottom under "STAPLEDON ADDITIONS".
The navbar logo and favicon are AILANG's, unaltered; the game's name is a typographic wordmark
(Montserrat) in the hero, not a logo.

`website/.gdignore` keeps Godot from importing this directory.

## Problem

1. **White dwarfs are dropped today.** The M1.2b-preflight probe
   (`.ailang/state/probe_M1.2b_iter4.json`, `real5k.counts = [5000, 4580, 324, 96]`)
   classifies 324 of the first 5,000 GCNS rows as white dwarfs
   (`WDprob > 0.5`) and gives them status `wd_deferred`. The full GCNS CSV has
   21,848 WD rows, all with G and BP−RP present (V-row G1). The package's
   dwarf relations (`teffFromBpRp`, `vFromG`) do not apply to them. Package
   0.2.0 has no WD model: E6 of the iteration-4 review found the WD search
   empty, with a positive control.
2. **The approved sprint text is underspecified and partly wrong.** Its task
   2 puts a new Planck integration in `catalogue.ail`, which breaks CLAUDE.md
   gate 3 (physics goes into the package first). It also uses "BP 505–680 nm,
   RP 640–1050 nm" rectangular bands. The real EDR3 BP response runs from
   325 to 750 nm, with 1 % of peak at 330–673 nm (V-row P2). A rectangular
   band has the wrong slope, not just an offset: between 4,000 K and 40,000 K
   the raw colour spans 1.38 mag with the old rectangles, but 2.00 mag
   through the real passbands (row P9). No constant zero point can fix that.
3. **No zero point, no weighting, no quadrature, no tolerance** (iteration-4
   designer item 2). `planck` returns spectral radiance only up to a
   constant. That constant cancels in a band ratio, but magnitude zero points
   are band-specific and do not cancel. Photon weighting versus energy
   weighting changes the raw BP−RP by 0.39 to 0.50 mag, depending on T
   (row P10), so the weighting must be chosen and stated.
4. **There is no V for WDs.** The catalogue stores Johnson V for brightness.
   `vFromG` uses the dwarf-sequence G−V, which is wrong for a WD.

## Goals and non-goals

**Goals**
- A package-first, pure, deterministic API in `sunholo/relativity` 0.3.0.
  It maps Gaia BP−RP to a blackbody T_eff and to a synthetic G−V, under one
  explicit convention: primary-source passbands, published zero points,
  photon weighting, a fixed quadrature and a fixed inversion bracket.
- An honest accuracy statement, measured against 1,780 real WDs and 12 named
  ones. It is not a tolerance invented to make the tests pass.
- Test check values derived independently (Appendix A). They agree between
  the AILANG VM and the interpreter under `--strict-bytecode`.
- A game-side pin to 0.3.0, and a written consumer contract for the later
  M1.2b transform task.

**Non-goals**
- WD model atmospheres (DA/DB grids, Balmer jump, collision-induced
  absorption). D-4 chose a blackbody. An empirical correction of the measured
  +3.8 % bias would change the accepted physical meaning, so it is not done.
- Reddening. It is negligible within 100 pc (M1 open question 2).
- Writing the catalogue transform or binary writer (later M1.2b tasks) and
  the UI label (the first per-star readout; see WD-3 obligations).
- Correcting Gaia's own blue-source BP systematic (see Risks).

## Design

### The convention, in one place

All magnitudes are Gaia EDR3/DR3 **VEGAMAG** (Riello et al. 2021, A&A 649,
A3, eq. 18), which is the system GCNS carries. For a source with spectrum
f_λ:

```
m_X = −2.5 log10( ∫ f_λ S_X(λ) λ dλ ) + ZP'_X            (photon counting: S_X·λ)
```

Here S_X is the published **photon** response (Riello eq. 10: "S includes
the scaling factor to convert from photons to e⁻"). A blackbody at T has
f_λ = k · B_λ(T), where k is unknown and the same in every band. So:

```
bbBpRp(T)    = −2.5 log10( Q_BP(T) / Q_RP(T) ) + Z_BPRP
bbGMinusV(T) = −2.5 log10( Q_G(T)  / Q_V(T)  ) + Z_GV
Q_X(T)       = Σ_i w_i · S_X(λ_i) · λ_i · planck(λ_i, T) · Δλ_X   (trapezoid, w = ½ at both ends)
```

`planck` is the existing `blackbody.planck` (µm⁻⁵ units; the constant
cancels in the ratio).

**Z_BPRP = ZP_BP − ZP_RP = 25.3385422158 − 24.7478955012 = 0.5906467146.**
The reason: Gaia's instrumental count is n_X = (P/hc) ∫ f S_X λ dλ with the
same pupil P and hc in every band, so for a common k:
BP − RP = −2.5 log10(Q_BP/Q_RP) + (ZP_BP − ZP_RP). The colour zero point is
therefore exactly the difference of the two published VEGAMAG zero points in
`zeropt.dat`. No Vega spectrum is needed and nothing is fitted. There are two
independent cross-checks (row P4):
- Pushing CALSPEC `alpha_lyr_mod_002` (the Vega spectrum Riello eq. 18
  names) through the published ZPs gives G, BP, RP = 0.0227, 0.0229, 0.0229.
  So Vega's colour is 0.0000 (5 × 10⁻⁵).
- Deriving Z from the Vega spectrum instead ("Vega colour 0") gives 0.5905943,
  5.2 × 10⁻⁵ mag from the ZP route.

**Z_GV = 2.5 log10( I_G(Vega) / I_V(Vega) ) + m_G(Vega) − V_Vega = 1.158256557.**
Johnson V has no Gaia ZP, so the Vega spectrum ties it in:
- I_X(Vega) = ∫ f_Vega S_X λ dλ on Vega's own 8,097-point grid.
- m_G(Vega) = 0.02268 (measured above through ZP_G).
- V_Vega = 0.03 (Bessell & Murphy 2012, Table 3 basis).

The V response is Bessell & Murphy 2012 Table 1, the **photonic** V
(470–740 nm at 10 nm), so it uses the same λ weighting.

The convention is checked against three external references:
- Synthetic V of CALSPEC GD 71, GD 153 and GD 50 against Landolt V:
  +0.0013, +0.0042 and −0.0156 mag (row P6).
- Synthetic G−V against observed G (DR3) − Landolt V: agrees within
  0.01 mag for the same three stars (row P6).
- Synthetic BP−RP from CALSPEC STIS spectra of 7 hot WDs against DR3 BP−RP:
  −0.013 to −0.031 mag, median −0.018 (row P5). This is the known EDR3
  systematic for bright, blue sources (Riello et al. 2021, abstract), and it
  sits in BP (ΔBP ≈ −0.015, ΔRP ≈ +0.003). It is not corrected here; see
  Risks.

**Passbands and quadrature (frozen):**

| Band | Source | Grid (nm) | Samples | Weighting |
|---|---|---|---|---|
| G | Gaia EDR3 `passband.dat` col 2 (Riello+2021, J/A+A/649/A3) | 320–1050, step 5 | 147 | photon, S·λ |
| BP | same, col 4 (defined 325–750; 1 % of peak at 330–673) | 325–750, step 5 | 86 | photon |
| RP | same, col 6 (defined 610–1080; 1 % of peak at 620–1042) | 610–1080, step 5 | 95 | photon |
| V | Bessell & Murphy 2012 Table 1 (photonic V) | 470–740, step 10 | 28 | photon |

The samples are the published values at those wavelengths, with no
interpolation (the Gaia file is at 1 nm; 99.99 means "undefined" and becomes
0). Quadrature error, 5 nm against 1 nm, over 3,000–100,000 K: at most
2.6 × 10⁻⁴ mag in BP−RP and 4.5 × 10⁻⁵ mag in G−V (row P8). For comparison,
10 nm would give 2.5 × 10⁻³ mag, because the BP blue edge is steep.

**Inversion.**
- Bracket: T ∈ [3,000 K, 100,000 K]. The blackbody colour over it runs from
  +2.216362 at 3,000 K down to −0.569816 at 100,000 K, strictly monotone.
- Coverage: all 21,848 GCNS WDs have BP−RP in [−0.514, 2.832]. None is bluer
  than the 100 kK edge. 13 (0.06 %) are redder than the 3,000 K edge; they
  clamp and are flagged (row G2).
- Two implementations, one definition:
  - `bbTeffFromBpRpExact(c)` does exactly 48 bisection halvings of ln T on
    the bracket, calling the forward model. A fixed count, no tolerance exit,
    so it is deterministic. Each call costs 48 forward evaluations (about
    17k `planck` calls), so it is used for tests and tools only.
  - `bbTeffFromBpRp(c)` is the production path. It interpolates linearly in
    (colour, ln T) over a **61-node table**, uniform in ln T across the
    bracket, whose nodes come from the forward model. Measured interpolation
    error against the exact solver: at most 4.99 × 10⁻⁴ relative in T_eff and
    at most 7.6 × 10⁻⁴ mag in G−V (row P11). The smallest spacing between
    node colours is 0.0042 mag.
  - Why a table: interpreter cost. On v0.47.2, 1,000 forward colours
    (180 k `planck` calls) take 4.84 s on the interpreter and 0.12 s on the
    VM (row A3). Bisection per WD would put medium-tier interpreter parity
    (about 3,300 WDs) near 12 minutes. The table costs about the same as the
    existing dwarf path (0.16 ms per row on the VM, preflight).
- Outside the bracket, and for non-finite input:
  - c ≥ colour(3,000 K), +∞ or NaN → **3000.0** exactly;
  - c ≤ colour(100,000 K) or −∞ → **100000.0** exactly;
  - `bbBpRpInvertible(c)` is false in all these cases.
  - NaN is tested first with `c == c`, because the v0.47.2 interpreter
    evaluates `NaN > 1.0` as true and the VM as false (row A4, reported
    upstream by the executor). The catalogue parser already rejects "NaN"
    (`checkPhotometry` in `catalogue_probe_test.ail`), so NaN is defensive
    only.
- Determinism: pure, no hidden state, and no floating-point tolerance
  branches except the fixed bracket tests.
  - Cross-language equality is by tolerance, not bits: Go's `exp`/`log`
    differ from CPython's libm by about 1 ulp
    (`exp(log(3000.0))` = 2999.9999999999973 in AILANG and
    2999.9999999999977 in CPython; row A5).
  - VM-versus-interpreter equality is by bits (AC-W5).

**Accuracy (the honest band; this goes into CHANGELOG and AGENT.md):**

| What | Measured | Row |
|---|---|---|
| Blackbody T_eff vs GF21 pure-H photometric T_eff, 1,780 WDs within 50 pc | median ratio 1.038; 68 % in [1.006, 1.052]; 95 % in [0.988, 1.065]; 99.2 % within 10 % | P12 |
| Same, by T_H bin | 3–5 kK: 0.998 · 5–7 kK: 1.032 · 7–10 kK: 1.048 · 10–15 kK: 1.051 · 15–25 kK: 1.030 · >25 kK (n = 9): 1.069, up to 1.17 | P12 |
| Against CALSPEC model T_eff, 7 hot DA/DB WDs (13.9–59 kK) | ratios 0.922 to 1.150 | P5 |
| G−V: blackbody at fitted T vs the real SED (7 CALSPEC WDs) | −0.006 to −0.039 mag; −0.090 for WD 1327-083 (strong Balmer lines) | P7 |
| Numerical: quadrature, table interpolation | ≤ 2.6 × 10⁻⁴ mag; ≤ 5.0 × 10⁻⁴ relative T | P8, P11 |

The stated product accuracy: **T_eff ±10 % (typically about 4 % too hot),
up to about +17 % above 25 kK, and V ±0.1 mag.** Visually this is harmless.
Above about 15 kK the blackbody colour saturates toward blue-white, so a
10–17 % T error barely moves the rendered RGB. At 7 kK, 4 % is about 280 K.
The error band is why every WD row carries `APPROX_TEFF`.

### WD-2: AILANG module, tests, publish 0.3.0 (package repo)

New module `sunholo/relativity/blackbody_photometry` (exported). It imports
`./blackbody (planck)`, `./blackbody_photometry_table (...)` and
`std/math (exp, log, log10)`.

```
export pure func bbTeffMin() -> float                      -- 3000.0
export pure func bbTeffMax() -> float                      -- 100000.0
export pure func bbBpRp(kelvin: float) -> float            -- forward, quadrature; requires kelvin > 0
export pure func bbGMinusV(kelvin: float) -> float         -- forward, quadrature; requires kelvin > 0
export pure func bbBpRpInvertible(bpRp: float) -> bool     -- bpRp == bpRp && colour(100k) < bpRp < colour(3000)
export pure func bbTeffFromBpRp(bpRp: float) -> float      -- 61-node table; ensures 3000 <= result <= 100000
export pure func bbTeffFromBpRpExact(bpRp: float) -> float -- 48-step ln-T bisection (tests and tools)
export pure func bbGMinusVFromBpRp(bpRp: float) -> float   -- same table; clamps to the end nodes
export pure func bbVFromG(g: float, bpRp: float) -> float  -- g - bbGMinusVFromBpRp(bpRp)
```

**Implementation rules:**
- **Quadrature.** Walk each response list with an accumulator on λ, by
  pattern match. Subtract ½(first + last) terms for the trapezoid. Never
  index with `nth_or` inside a loop (the M1.1 O(n²) trap). The table
  interpolation walks the three node lists together in one pass.
- **Test style.** Test blocks call named `checkNN()` functions, following
  the CLAUDE.md workaround for float literals in test blocks.

**Tests** go in `blackbody_photometry_test.ail`. They are written first and
use the values from Appendix A's run.

## Appendix A: reference script (run 2026-09-30)

This is the stdlib-only reference whose output gives every check value
above. WD-1 turns it into `tools/gaia_bb_to_ail.py` by adding sha256
verification and the `.ail` emitter; the maths stays unchanged. The inputs
are listed in row P1, plus `gf21.tsv` (row P12). The V table is typed in from
Bessell & Murphy 2012 Table 1.

```python
#!/usr/bin/env python3
"""Reference for sunholo/relativity 0.3.0 blackbody Gaia photometry (stdlib only).
usage: WDREF=<dir> python3 wdbb_ref.py [check|validate]   (inputs + sha256: doc §Verification)"""
import math, os, struct, sys
D = os.environ.get("WDREF", "/tmp/wdref")
C2 = 14387769.0                                   # nm K, as blackbody.c2()
PB = f"{D}/pb/GaiaEDR3_passbands_zeropoints_version2"
BM12_V = [0.000, 0.033, 0.176, 0.485, 0.811, 0.986, 1.000, 0.955, 0.865, 0.750, 0.656, 0.545, 0.434, 0.334,
          0.249, 0.180, 0.124, 0.075, 0.041, 0.022, 0.014, 0.011, 0.008, 0.006, 0.004, 0.002, 0.001, 0.000]
GRID = {"G": (320, 1050, 5), "BP": (325, 750, 5), "RP": (610, 1080, 5), "V": (470, 740, 10)}  # nm lo, hi, step
VEGA_V = 0.03                                     # Bessell & Murphy 2012, V of Vega
TLO, THI, N = 3000.0, 100000.0, 61

def load_bands():
    b = {"G": {}, "BP": {}, "RP": {}}
    for line in open(f"{PB}/passband.dat"):
        r = line.split(); lam = float(r[0])
        for col, k in ((1, "G"), (3, "BP"), (5, "RP")):
            b[k][lam] = 0.0 if r[col] == "99.99" else float(r[col])
    b["V"] = {470.0 + 10 * i: s for i, s in enumerate(BM12_V)}
    return b

def fits_spectrum(path):                          # CALSPEC BINTABLE: WAVELENGTH [A], FLUX [FLAM]
    d = open(path, "rb").read(); off = 0
    while True:
        cards = {}
        while True:
            blk = d[off:off + 2880]; off += 2880
            cs = [blk[i:i + 80].decode("ascii", "replace") for i in range(0, 2880, 80)]
            for c in cs:
                if "=" in c[:10]: cards[c[:8].strip()] = c[10:].split("/")[0].strip().strip("'").strip()
            if any(c.startswith("END") for c in cs): break
        naxis = int(cards.get("NAXIS", 0))
        if cards.get("XTENSION", "").startswith("BINTABLE"):
            n1, n2 = int(cards["NAXIS1"]), int(cards["NAXIS2"])
            forms = [cards[f"TFORM{i + 1}"] for i in range(int(cards["TFIELDS"]))]
            names = [cards[f"TTYPE{i + 1}"] for i in range(len(forms))]
            fmt = ">" + "".join({"1D": "d", "1E": "f", "1I": "h", "1J": "i"}[f] for f in forms)
            rows = [struct.unpack(fmt, d[off + j * n1: off + (j + 1) * n1]) for j in range(n2)]
            return [r[names.index("WAVELENGTH")] / 10 for r in rows], [r[names.index("FLUX")] for r in rows], cards
        size = abs(int(cards["BITPIX"])) // 8 * math.prod(int(cards[f"NAXIS{i + 1}"]) for i in range(naxis)) if naxis else 0
        off += (size + 2879) // 2880 * 2880

B = load_bands(); KEYS = {k: sorted(v) for k, v in B.items()}
def resp(k, lam):                                 # linear interpolation of the tabulated response
    ks = KEYS[k]
    if lam <= ks[0] or lam >= ks[-1]: return 0.0
    lo, hi = 0, len(ks) - 1
    while hi - lo > 1:
        m = (lo + hi) // 2; lo, hi = (m, hi) if ks[m] <= lam else (lo, m)
    a, b = ks[lo], ks[hi]
    return B[k][a] + (B[k][b] - B[k][a]) * (lam - a) / (b - a)

def spec_int(k, wl, fl):                          # photon count ∝ ∫ f S λ dλ on the spectrum's own grid
    lo, hi, _ = GRID[k]; s = 0.0
    for i in range(len(wl) - 1):
        a, b = wl[i], wl[i + 1]
        if lo <= a and b <= hi:
            s += 0.5 * (resp(k, a) * a * fl[i] + resp(k, b) * b * fl[i + 1]) * (b - a)
    return s

def planck(l, T):                                 # same form as blackbody.planck
    e = C2 / (l * T)
    return 0.0 if e > 700.0 else (l / 1000.0) ** -5 / math.expm1(e)

def q(k, T, step=None):                           # package quadrature: trapezoid on the fixed grid
    lo, hi, st = GRID[k]; st = step or st; n = round((hi - lo) / st)
    return st * sum((0.5 if i in (0, n) else 1.0) * resp(k, lo + st * i) * (lo + st * i) * planck(lo + st * i, T)
                    for i in range(n + 1))

wl, fl, _ = fits_spectrum(f"{D}/vega.fits")       # alpha_lyr_mod_002 (Riello+2021 eq. 18)
VI = {k: spec_int(k, wl, fl) for k in GRID}

VEGA_GAIA = {k: -2.5 * math.log10(0.7278 * VI[k] * 1e-2 * 1e-9 / 1.98644586e-25) + ZP[k] for k in ZP}
Z_BPRP = ZP["BP"] - ZP["RP"]                      # P/hc cancels: the colour ZP is the ZP difference
Z_BPRP_VEGA = 2.5 * math.log10(VI["BP"] / VI["RP"])  # cross-check: Vega colour 0 by Riello eq. 18
Z_GV = 2.5 * math.log10(VI["G"] / VI["V"]) + VEGA_GAIA["G"] - VEGA_V

def bprp(T, step=None): return -2.5 * math.log10(q("BP", T, step) / q("RP", T, step)) + Z_BPRP
def gmv(T, step=None): return -2.5 * math.log10(q("G", T, step) / q("V", T, step)) + Z_GV
def exact(c):                                     # 48 fixed bisection halvings in ln T
    if not c == c or c >= bprp(TLO): return TLO
    if c <= bprp(THI): return THI
    a, b = math.log(TLO), math.log(THI)
    for _ in range(48):
        m = 0.5 * (a + b); a, b = (m, b) if bprp(math.exp(m)) > c else (a, m)
    return math.exp(0.5 * (a + b))

LNT = [math.log(THI) + (math.log(TLO) - math.log(THI)) * i / (N - 1) for i in range(N)]  # colour ascending
COL = [bprp(math.exp(x)) for x in LNT]; GV = [gmv(math.exp(x)) for x in LNT]
def table(c, ys):
    if not c == c or c >= COL[-1]: return ys[-1]
    if c <= COL[0]: return ys[0]
    i = next(i for i in range(N - 1) if c <= COL[i + 1])
    return ys[i] + (c - COL[i]) * (ys[i + 1] - ys[i]) / (COL[i + 1] - COL[i])
def teff(c): return TLO if not c == c or c >= COL[-1] else THI if c <= COL[0] else math.exp(table(c, LNT))

    print(f"Z_BPRP_VEGA={Z_BPRP_VEGA:.12f} (diff {Z_BPRP - Z_BPRP_VEGA:+.1e})")

    sweep = [math.exp(math.log(TLO) + (math.log(THI) - math.log(TLO)) * i / 400) for i in range(401)]

    print("digest(400) =", repr(sum(teff(-0.6 + 2.9 * i / 400) for i in range(401))))
```

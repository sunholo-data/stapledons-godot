### Changed

- **The Live AI panel and badge are pictures, not debug text** (R3-AI-PANEL-V2; Mark, 2026-11-09: "its a big mess of debug text an we make it a nice UI", mock-up approved the same day). The badge in the top right is a spend ring, a lamp and one word: off, live, thinking, key problem or offline, ceiling. The exact amounts moved to its tooltip. The panel has a switch, then a card per key with a lamp and word (No key, Saved, Checking…, Working, Key rejected, Offline). Each card has four tiles that light up for what the key powers (crew and Archive lines, voices, portraits, pictures from home) and shows the key by its last 4 characters. Below the cards are this session's spend as a bar against the ceiling (a log slider, $0.05 to $20), the prices as chips and the last 8 replies as dots. The warning sits behind a lock.
- The panel and badge now use the game's theme. Their CanvasLayer never passed it down, so in a voyage they had drawn in Godot's default look.

### Added

- **Test a key from the panel.** One free call to the provider (Gemini `models.list`, OpenRouter `/api/v1/key`) says whether the key works. It runs as a short AILANG process (`ai/check.ail`, `AiKeyCheck`) under `env -i`, with the key passed as a 0600 file path and only the provider hosts reachable. It writes no usage line, never runs in automation, and is killed after 10 s (reported as offline). Results last for this run only. Checked on 2026-11-09 against Google: a real key reads ok, a fake one rejected.
- `make ai-key-check` (in `ai-test`): the real check against the loopback, covering 8 outcomes (ok, rejected, offline and no key for each provider), the auth headers, no files written and no key text in any output. `make ai-key-check-mutants` (in `ai-mutants`) checks that printing a body, printing the key or writing a file each fails it by name. There are 8 new GDScript mutant rows (badge precedence, the slider's snap, the masked key, the tiles, the check's guards and timeout) and 2 AILANG rows.
- `make ai-panel-capture` writes six review renders to `renders/ai_panel/` (no key, working, rejected, offline, text only, ceiling) and fails if the panel overflows the 960×540 UI space.
